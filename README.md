# 나의 수업 아카이브 · 사용 설명서

제주대학교 청년도약 인재양성 **AI콘텐츠 부트캠프 1기**(2026.10.26 ~ 11.4)를 위한 개인 아카이브입니다.
수업 노트 · 회고 · 강의 자료 · 결과물 · 포트폴리오를 한곳에 모으고, Claude · ChatGPT AI 스킬로 정리까지 도와줍니다.

## 잠금 PIN과 정보 보호

- 처음 열면 **PIN 입력 화면**이 나옵니다. 초기 PIN은 과정 담당자에게 받은 번호입니다. 코드에는 PIN이 저장되지 않고 확인용 해시만 들어 있습니다.
- PIN을 맞게 입력해야 기록이 복호화되어 화면에 나타납니다. 5번 틀리면 30초부터 최대 15분까지 입력이 잠깁니다.
- 노트 · 회고 · 체크리스트 · 실습 시간 · AI 기록 · 업로드 파일(이름 포함) · API 키는 모두 **AES-256으로 암호화**되어 저장됩니다.
- 저장 폴더(`archive.json`, `files/*.bin`)와 백업 파일도 암호화되어 PIN 없이는 열 수 없습니다.
- **자동 잠금**(기본 15분), **다른 창으로 전환하면 화면 흐리게 가리기**, 상단의 **잠금** 버튼을 지원합니다.
- 허용된 곳(Claude · OpenAI API, 글꼴 서버)이 아닌 곳으로는 데이터를 보낼 수 없도록 브라우저 보안 정책(CSP)을 적용했습니다.
- **보안 · 연동 설정**에서 PIN을 6자리 이상으로 바꾸는 것을 권장합니다. 4자리 PIN은 파일을 가진 사람이 오래 시도하면 풀릴 수 있습니다.
- **PIN을 잊으면 기록을 복구할 수 없습니다.** PIN을 안전한 곳에 따로 적어 두세요.
- 포트폴리오 HTML과 노트 `.md` 내보내기는 공개용이라 암호화되지 않습니다.

## 화면 상단 바

현재 시간 · **실습 타이머**(수업 선택, 목표 25/50/90분 알림, 일시정지, 끝내고 기록 저장) · 자동 저장 상태 · 다크/라이트 테마 · 잠금 버튼이 항상 표시됩니다.
타이머는 새로고침하거나 잠가도 이어서 계속 측정되고, 기록은 각 DAY 페이지의 **실습 시간 기록**에서 바로 수정 · 삭제할 수 있습니다.

## 폴더 구성

| 파일 | 역할 |
| --- | --- |
| `index.html` | 아카이브 앱 (이 파일 하나만 열어도 동작) |
| `server.js` | 로컬 서버 — `.env`의 API 키로 AI를 대신 호출 (외부 패키지 없음) |
| `start.bat` | 더블클릭으로 로컬 서버 실행 + 브라우저 열기 (Windows) |

| `.gitignore` | `.env`가 GitHub에 올라가지 않도록 제외 |

> 이 파일들은 **같은 폴더**에 함께 두세요.

## USB 휴대 모드 — 노트북 · 새 PC · 학교 PC 번갈아 쓰기

이 폴더는 USB에 들어 있고, **USB의 `data\` 폴더가 유일한 원본**입니다 (`portable.json` 파일이 있으면 USB 모드).
USB 안에 Node.js(`runtime\node.exe`)가 들어 있어서 어느 PC에도 설치할 것이 없습니다.

**처음 쓰는 PC에서 한 번만**
- USB의 `PC에 바로가기 만들기.vbs`를 더블클릭 → 바탕화면에 **나의 수업 아카이브** 아이콘이 생깁니다.
  (USB 드라이브 문자가 D:, E: 등으로 바뀌어도 아이콘이 USB를 찾아 엽니다. 아이콘 없이 쓰려면 USB의 `아카이브 열기.vbs`를 바로 실행해도 됩니다.)

**매번**
1. USB를 꽂고 아이콘을 누릅니다 → 앱 창이 열립니다.
2. PIN을 입력하면 USB의 최신 기록이 자동으로 열립니다.
3. 다 쓰면 상단의 **USB 안전하게 빼기**를 누릅니다 → USB에 저장을 마치고, 그 PC 브라우저의 기록 사본을 지우고, 서버를 끕니다. "USB를 빼도 돼요"가 나오면 USB를 뺍니다.

**알아 두기**
- 잠금 버튼을 눌러도 USB에 저장한 뒤 그 PC의 사본을 지웁니다. 창만 닫으면 암호화된 사본이 그 PC에 남을 수 있으니, 공용 PC에서는 꼭 **USB 안전하게 빼기**를 쓰세요.
- 어느 PC에서 PIN을 바꾸면 다른 PC에서도 바뀐 PIN으로 열립니다.
- 화면에서 입력한 API 키도 암호화되어 USB에 보관됩니다. (`.env`는 평문이므로 USB 모드에서는 화면 입력을 권장)
- **USB를 잃어버리면 기록도 함께 잃습니다.** 가끔 **백업 · 동기화 → 백업 파일 내보내기**로 다른 곳에 사본을 두세요(암호화된 파일).
- 같은 USB를 두 PC에 동시에 꽂아 쓸 수는 없으니 걱정할 충돌은 없습니다.

## 시작하기 (자세히)

### 방법 A · 로컬 서버 + 환경변수 (권장, 가장 안전)
1. [Node.js](https://nodejs.org/ko) LTS 버전을 설치합니다.
2. `start.bat`을 더블클릭합니다. 처음 실행하면 `.env` 파일이 자동으로 만들어집니다.
3. `.env`를 메모장으로 열어 키를 붙여넣고 저장합니다.
   ```
   ANTHROPIC_API_KEY=sk-ant-...
   OPENAI_API_KEY=sk-...
   ```
4. `start.bat` 창을 닫고 다시 실행하면 브라우저가 `http://localhost:5174`로 열립니다.
5. **AI · 연동 설정** 화면 맨 위가 "로컬 서버 모드"로 표시되면 연동 완료입니다.

API 키는 `.env`에만 있고 브라우저로 전달되지 않습니다. (수업의 "API 키는 환경변수에"와 같은 원리)

Mac · Linux에서는 터미널에서 `node server.js --open`으로 실행하세요.

### 방법 B · 파일로 바로 열기
`index.html`을 Chrome 또는 Edge로 엽니다. AI를 쓰려면 **AI · 연동 설정**에서 API 키를 입력하세요.
키는 그 브라우저에만 저장되며, 공용 PC에서는 "이 PC에 기억하기"를 끄세요.

> 파일로 열 때(`file://`)와 서버로 열 때(`localhost`)는 브라우저 저장 공간이 서로 다릅니다.
> 방식을 바꿀 때는 **백업 · 동기화 → 저장 폴더 연결**에서 같은 폴더를 연결하면 기록이 그대로 이어집니다.

## 주요 기능

- **대시보드** — 진행률, 8일간의 여정, 최근 기록, 결과물 갤러리
- **DAY 1~8** — 수업 노트(Markdown), 회고(KPT), 체크리스트, 결과물, 강의 자료, AI 도우미
- **아카이브** — 날짜별 · 수업 노트 · 자료실 · 결과물 갤러리
- **포트폴리오** — 입력한 내용으로 나만의 포트폴리오 웹페이지를 만들어 HTML로 내보내기
- **AI 스튜디오** — Claude · ChatGPT 스킬 22가지 (결과를 노트 · 회고 · 결과물 설명 · 자기소개에 바로 넣기)
  - 학습 정리: 노트 정리, 회고(KPT) 초안, 핵심 용어 설명, 복습 퀴즈
  - 개발 · JavaScript: 코드 설명, 오류 해결(스크린샷 가능), 기능 코드 만들기, API 키 · 환경변수 점검
  - 프롬프트: 프롬프트 다듬기, 에이전트 시스템 프롬프트 설계
  - 디자인 · UI/UX: 화면 UI/UX 리뷰(스크린샷), 브랜드 컬러 · 폰트, UX 문구 다듬기
  - 포트폴리오: 결과물 설명, GitHub README 초안, 자기소개 다듬기
- **REA 안전 분석실** — 파일을 실행하지 않고 구조와 단서를 확인하는 읽기 전용 분석
  - USB 오프라인 모드: SHA-256, 파일 형식, 표본 엔트로피, 문자열·URL, 헥스 미리보기
  - REA 데스크톱 모드: 트리아지, 문자열·바이트 검색, 디스어셈블, 함수·참조 추적, APK, HAR
  - 분석 보고서만 PIN 암호화 기록에 저장하며 원본 파일은 보관하지 않음
  - AI 스튜디오의 REA 스킬 6개로 결과 설명·신호 분류·함수 흐름·API 명세·보고서 작성
- **사이트 모음** — 수업에서 공유된 사이트 기록 + AI · 개발 · 디자인 · 제주 공공데이터 API 추천 목록
- **백업 · 동기화** — OneDrive · Google Drive · USB 폴더에 자동 저장, 백업 파일 내보내기/불러오기
- **AI · 연동 설정** — API 키, 모델 선택, 연결 테스트

## REA 안전 분석실 사용법

1. 왼쪽 메뉴에서 **REA 안전 분석실**을 엽니다.
2. 검사할 파일을 선택하고 **안전 분석 시작**을 누릅니다.
3. 형식, SHA-256, 엔트로피, URL·문자열 단서와 헥스 미리보기를 확인합니다.
4. REA가 설치된 PC에서는 **심층 분석**에서 필요한 기능을 선택합니다.
5. 필요한 결과만 **암호화 기록에 저장**하거나 복사해 AI 스튜디오의 REA 스킬에서 설명을 받습니다.

### 분석 개인정보 기준

- 오프라인 분석은 파일을 브라우저 메모리에서만 읽고 외부 서버로 보내지 않습니다.
- 심층 분석은 같은 PC의 `localhost` 서버만 사용합니다. 임시 파일은 운영체제 임시 폴더에서 처리 후 삭제됩니다.
- AI 스튜디오에는 원본 파일이 아니라 사용자가 검토한 분석 요약만 붙여넣으세요.
- 토큰, 비밀번호, 쿠키, API 키, 고객·동료 개인정보, 호텔 내부 URL은 AI 전송 전에 삭제하세요.
- 정적 분석 결과만으로 안전·악성 여부를 단정하지 마세요. `확인 필요`와 근거를 함께 기록하세요.

### 심층 분석을 사용할 수 없는 경우

화면에 **오프라인 모드**가 표시되면 USB 기본 분석은 그대로 사용할 수 있습니다. 이 PC에서 심층 분석이 필요하면 REA를 설치·등록한 뒤 아카이브를 다시 여세요. REA가 없는 학교·공용 PC에서도 파일을 실행하지 않는 기본 분석은 동작합니다.

### REA 기능 자체 점검

앱을 수정하거나 USB를 다른 PC로 옮긴 뒤에는 다음 명령으로 화면 연결과 보안 안전장치를 확인할 수 있습니다.

```bat
runtime\node.exe --test tests\rea-smoke.test.js
```

`pass 5`, `fail 0`이면 화면 스크립트, 메뉴·라우팅, 암호화 보고서 상태, 명령 허용 목록, 임시 파일 삭제 규칙이 정상입니다. 실제 심층 분석 가능 여부는 REA 분석실 상단의 연결 상태에서 별도로 확인하세요.

## 데이터와 보안

- 기록은 브라우저에 암호화되어 자동 저장되고(입력 즉시 + 30초마다), 저장 폴더를 연결하면 암호화된 `archive.json` · `files/*.bin`으로도 저장됩니다.
- **API 키는 백업 파일 · 저장 폴더 · 포트폴리오 HTML에 절대 포함되지 않습니다.**
- 로컬 서버는 이 PC(127.0.0.1)에서만 열리고, 다른 웹사이트에서 오는 요청과 `.env` 같은 숨김 파일 접근을 차단합니다.
- API는 사용한 만큼 요금이 나옵니다. 각 콘솔에서 사용 한도를 설정해 두세요.
- 키가 노출되었다면 즉시 콘솔에서 폐기하고 새로 발급하세요.

## 문제 해결

| 증상 | 해결 |
| --- | --- |
| "API 키가 올바르지 않아요" | 키를 공백 없이 다시 붙여넣기 → 연결 테스트 |
| "모델을 찾을 수 없어요" | AI · 연동 설정 → "연결 테스트 · 모델 목록 불러오기" 후 목록에서 선택 |
| "크레딧이 부족해요" (429) | 콘솔에서 결제 · 사용 한도 확인, 잠시 후 다시 시도 |
| start.bat이 바로 닫힘 | Node.js 설치 확인, 이미 실행 중이면 `http://localhost:5174` 직접 열기 |
| 폴더 "다시 연결" 버튼이 보임 | 브라우저 보안 정책상 정상 — 한 번 눌러 주면 이어서 저장 |
